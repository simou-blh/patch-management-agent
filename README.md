Intillegent deplyment kit is our school project for deployment and patch management on Debian VMs. The agent runs on Pi or OpenCode and uses MCP to gather host information with osquery and run approved Ansible workflows through Semaphore.

The planned backend uses Python, FastAPI, and SQLite. The project is currently in the planning stage. The architecture, Agile phases, tests, and demo scenarios are in [plan.md](plan.md).

We work on separate branches and submit changes through pull requests. Team members can merge PRs after review. Checking off completed items in [plan.md](plan.md) helps track progress, but is optional.
